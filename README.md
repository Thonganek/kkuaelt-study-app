# KKU-AELT Study App — หลักสูตร 60 Day เป้าหมาย Band 7

KKU-AELT ประเมินผลเป็น 7 ระดับ หลักสูตรนี้ตั้งเป้าที่ **Band 7** ซึ่งเป็นระดับสูงสุด ทำ **Day 1–60** ตามลำดับได้ตามจังหวะของตัวเอง ไม่ผูกกับวันที่ และข้อสอบไม่ตัดเวลา

- **เปิดเว็บ:** [KKU-AELT Study App](https://thonganek.github.io/kkuaelt-study-app/KKU-AELT_Full_Course.html#/today)
- **เปิดออฟไลน์:** `KKU-AELT_Full_Course.html` ด้วย Chrome หรือ Edge

## โครงหลักสูตร

| ช่วง | Day | เนื้อหา |
|---|---|---|
| พื้นฐานและกลยุทธ์ | 1–37 | Reading Test 1–6, บทอ่านรายวัน 31 บท, Grammar 30 บท, Essay ทุกสัปดาห์, ศัพท์ AWL + ศัพท์หัวข้อ 740 คำ |
| วัดผลก่อนเข้าช่วง Band 7 | 38–40 | Full Mock 1–3 |
| **ช่วง Band 7** | 41–58 | Reading Test ระดับยาก 3 ชุด (A1–A3), Band 7 Mock 2 ชุด (AM1–AM2), บทอ่านยากรายวัน 10 บท (B01–B10) พร้อมบทเรียนกลยุทธ์, Grammar ขั้นสูง 5 บท (G31–G35), Essay โจทย์ใหม่ 5 เรื่อง (BE1–BE5) พร้อมตัวอย่างระดับ Band 7, Academic Vocabulary 300 คำ วันละ 20 คำ |
| ทบทวน | 59–60 | ทำข้อผิดซ้ำ ทวนศัพท์ และทบทวนเบา ๆ |

ข้อสอบช่วง Band 7 ยากกว่าชุดเดิม บทอ่านยาวขึ้น (บทสั้น 400–500 คำ บทยาว 950–1,150 คำ) ใช้ภาษาวิชาการระดับ C1 และเน้นข้อ inference, purpose, tone และ paraphrase ตัวลวงทุกข้อออกแบบให้ใกล้เคียงคำตอบ ข้อสอบใหม่ทุกชุดผ่านการตรวจแบบไม่เห็นเฉลย ผู้ตรวจตอบตรงกับเฉลยทุกข้อ

## ไม่จำกัดเวลา

- หน้า “วันนี้” เปิด Day แรกที่ยังไม่เสร็จ จะทำวันละกี่ Day ก็ได้
- Reading Test และ Mock ไม่ตัดเวลาและไม่ส่งอัตโนมัติ นาฬิกาแสดงเวลาที่ใช้ไป ออกจากหน้าข้อสอบแล้วนาฬิกาหยุด
- เวลาในแผนเป็นค่าประมาณ ส่วนแผนเวลาในคู่มือคือเวลาของวันสอบจริง (Reading 120 + Writing 60 นาที)

## ความคืบหน้า

ข้อมูลบันทึกในเบราว์เซอร์และใช้ต่อจากฉบับก่อนได้ Day 1–40 คงความคืบหน้าเดิม งานของ Error Review และ Light Review เดิมย้ายไปอยู่ Day 59–60 รายการศัพท์เปลี่ยน จึงเริ่ม Quiz คำศัพท์ใหม่ แต่วันที่เคยทำ Quiz ศัพท์แล้วยังติ๊กเสร็จไว้ มีปุ่มสำรอง/กู้คืนเป็น JSON ในหน้าตั้งค่า

## สร้างไฟล์

```powershell
python build/src/build_full.py   # สร้าง KKU-AELT_Full_Course.html (ไฟล์ที่เผยแพร่บนเว็บ)
```

ซอร์สอยู่ที่ `build/src/build_full.py`, `build/src/band7.py` และ `build/src/js/full_course.js` โดยอ่านเนื้อหาจาก `KKU-AELT_42_Day_Study_Plan_Original.html`, ศัพท์ชุดใหม่จาก `build/content/vocab_academic.json` และเนื้อหาช่วง Band 7 จาก `build/content/band7/` (ข้อกำหนดอยู่ที่ `build/spec/band7_spec.md`)

เอกสารต้นฉบับ PDF/DOCX ไม่ได้เผยแพร่ใน repository ปุ่มเปิดเอกสารใช้ได้เมื่อวางไฟล์ต้นฉบับไว้ข้าง HTML ในเครื่อง คลังบทเรียนและข้อสอบในแอปใช้ได้บนเว็บ

ข้อสอบในแอปแต่งขึ้นเพื่อการฝึก ไม่ใช่ข้อสอบจริง คะแนนร้อยละไม่ใช่ระดับคะแนนทางการ
