# KKU-AELT Study App — หลักสูตรเต็ม ไม่จำกัดเวลา

หลักสูตรเต็ม **Day 1–42** ทำตามลำดับได้ตามจังหวะของตัวเอง ไม่ผูกกับวันที่ ไม่มีวันหมดเขต และข้อสอบไม่ตัดเวลา

- **เปิดเว็บ:** [KKU-AELT Study App](https://thonganek.github.io/kkuaelt-study-app/KKU-AELT_Full_Course.html#/today)
- **เปิดออฟไลน์:** `KKU-AELT_Full_Course.html` ด้วย Chrome หรือ Edge

## เนื้อหา

| หมวด | จำนวน |
|---|---|
| คำศัพท์ | **1,040 คำ** = AWL + ศัพท์หัวข้อ 740 คำ + **Academic Vocabulary เพิ่ม 300 คำ** (วันละ 8–9 คำ) |
| บทอ่าน | 85 บท (รายวัน 31 + Reading Test 6 ชุด + Full Mock 3 ชุด) |
| Grammar | 30 บท พร้อม quiz |
| Writing | งานเขียนย่อยทุกวัน + Essay เต็ม พร้อมคลังหัวข้อและตัวอย่าง |

ในหน้าคำศัพท์กด “Academic +300” เพื่อดูเฉพาะคำชุดใหม่ ทุกคำมีความหมายภาษาไทย ครอบครัวคำ คำที่มักใช้คู่ และประโยคตัวอย่าง

## ไม่จำกัดเวลา

- หน้า “วันนี้” เปิด Day แรกที่ยังไม่เสร็จ จะทำวันละกี่ Day ก็ได้
- Reading Test และ Full Mock ไม่ตัดเวลาและไม่ส่งอัตโนมัติ นาฬิกาแสดงเวลาที่ใช้ไป ออกจากหน้าข้อสอบแล้วนาฬิกาหยุด กลับมาทำต่อได้
- ปุ่มจับเวลาในแบบฝึกเป็นนาฬิกาจับเวลา กดพักได้ เวลาในแผนเป็นค่าประมาณ ส่วนแผนเวลาในคู่มือคือเวลาของวันสอบจริง

## ความคืบหน้า

ข้อมูลบันทึกในเบราว์เซอร์ เปิดครั้งแรกจะนำความคืบหน้าของแผน 42 วันเดิมมาใช้ให้ ศัพท์แต่ละวันเพิ่มขึ้น จึงเริ่ม Quiz คำศัพท์ใหม่ ส่วนวันที่เคยทำ Quiz ศัพท์แล้วยังติ๊กเสร็จไว้เหมือนเดิม มีปุ่มสำรอง/กู้คืนเป็น JSON ในหน้าตั้งค่า

## สร้างไฟล์

```powershell
python build/src/build_full.py   # สร้าง KKU-AELT_Full_Course.html (ไฟล์ที่เผยแพร่บนเว็บ)
```

ซอร์สอยู่ที่ `build/src/build_full.py` และ `build/src/js/full_course.js` โดยอ่านเนื้อหาจาก `KKU-AELT_42_Day_Study_Plan_Original.html` และศัพท์ชุดใหม่จาก `build/content/vocab_academic.json`

เอกสารต้นฉบับ PDF/DOCX ไม่ได้เผยแพร่ใน repository ปุ่มเปิดเอกสารใช้ได้เมื่อวางไฟล์ต้นฉบับไว้ข้าง HTML ในเครื่อง คลังบทเรียนและข้อสอบในแอปใช้ได้บนเว็บ

ข้อสอบในแอปแต่งขึ้นเพื่อการฝึก ไม่ใช่ข้อสอบจริง คะแนนร้อยละไม่ใช่ระดับคะแนนทางการ
