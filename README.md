# KKU-AELT Study App — แผนเร่งรัด 6 วัน

แผนอ่าน **8–13 ตุลาคม 2569** พร้อมศัพท์ใหม่ **วันละ 100 คำ รวม 600 คำไม่ซ้ำกัน** และแบบทดสอบศัพท์วันละ 100 ข้อ

- **เปิดเว็บ:** [KKU-AELT Study App](https://thonganek.github.io/kkuaelt-study-app/KKU-AELT_42_Day_Study_Plan.html#/today) — ลิงก์เดิมแสดงแผน 6 วันล่าสุด
- **เปิดออฟไลน์:** `KKU-AELT_6_Day_Study_Plan_08-13_Oct_2569.html` ด้วย Chrome หรือ Edge
- ทุกวันเริ่ม **คำศัพท์ → Reading → Writing** แล้วจึงทบทวนและจดข้อผิดพลาด
- คลังเพิ่มเติมยังมีศัพท์ครบ 740 คำ บทอ่าน 85 บท Grammar 30 บท และข้อสอบฝึกทุกชุด

## แผนรายวัน

| วันที่ | Reading | Writing |
|---|---|---|
| 8 ต.ค. | Reading Test 1 วัดระดับ 120 นาที | ย่อหน้าวัดระดับ 100–120 คำ |
| 9 ต.ค. | Previewing + Main idea | โครงประโยค Grammar และบทนำ |
| 10 ต.ค. | Scanning + Short answer + Inference | Body paragraph และคำเชื่อม |
| 11 ต.ค. | Reading จับเวลา | Essay เต็ม 60 นาที |
| 12 ต.ค. | Mock M1: Reading 120 นาที | Mock: Writing 60 นาทีต่อเนื่อง |
| 13 ต.ค. | Reading เบา ๆ และทบทวนข้อผิด | แก้งานเขียนและสรุปแม่แบบ |

เรียนศัพท์ใหม่ 100 คำก่อน Reading ทุกวัน โดยจัดเวลาเรียนศัพท์วันละ 75 นาที และทวนศัพท์สะสมในวันสุดท้าย

## ความคืบหน้า

หน้า “วันนี้” เปิด Day แรกที่ยังไม่เสร็จ ติ๊กสถานะได้ที่หน้า “ที่ต้องทำ” และสลับเป็นตามวันที่ปฏิทินได้ในตั้งค่า ข้อมูลบันทึกในเบราว์เซอร์ มีปุ่มสำรอง/กู้คืนเป็น JSON

แผน 6 วันใช้พื้นที่บันทึกแยกจากแผน 42 วัน เมื่ออัปเดตจากศัพท์ชุดเดิมเป็นวันละ 100 คำ ระบบเก็บผลศัพท์เดิมไว้ในข้อมูลสำรองภายใน และคงงานเขียน บันทึก Reading และคำศัพท์ที่ติดดาวไว้

## สร้างไฟล์

```powershell
python build/src/build6.py           # สร้างไฟล์แผน 6 วัน
python build/src/build6.py --deploy  # สร้างพร้อมอัปเดตไฟล์หน้าเว็บที่ลิงก์เดิม
```

ซอร์สของฉบับ 6 วันอยู่ที่ `build/src/build6.py` และ `build/src/js/six_day.js` โดยอ่านเนื้อหาต้นฉบับจาก `KKU-AELT_42_Day_Study_Plan_Original.html` ข้อมูลบทเรียนเพิ่มเติมอยู่ใน `build/content/`

เอกสารต้นฉบับ PDF/DOCX ไม่ได้เผยแพร่ใน repository ปุ่มเปิดเอกสารใช้ได้เมื่อวางไฟล์ต้นฉบับไว้ข้าง HTML ในเครื่อง คลังบทเรียนและข้อสอบในแอปใช้ได้บนเว็บ

ข้อสอบในแอปแต่งขึ้นเพื่อการฝึก ไม่ใช่ข้อสอบจริง คะแนนร้อยละไม่ใช่ระดับคะแนนทางการ
